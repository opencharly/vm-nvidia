## How tested

**This repo's own box was built**, not a different repo's:

```console
$ charly -C . box build vm-nvidia
rc=0

$ podman run --rm --entrypoint sh localhost/vm-nvidia:2026.322.1322 \
    -c 'command -v nvidia-ctk; pacman -Q nvidia-utils'
nvidia-ctk: ABSENT
nvidia-utils: nvidia-utils 620.70.06-2
```

**That result is a defect, and I am not dressing it up.** A passthrough guest must carry
`/usr/bin/nvidia-ctk`, and this image does not — even though it pins
`layer-nvidia:v2026.322.1139`, the tag that carries the merged step installing
`extra/nvidia-container-toolkit`. The step is emitted but does not take effect, which is
**opencharly/charly#1202**, confirmed here from a second independent consumer.

**Not proven:** a VM boot with GPU passthrough. There is no such guest on this host, so this
box's runtime behaviour cannot be demonstrated. That is why the tier below is what it is.
